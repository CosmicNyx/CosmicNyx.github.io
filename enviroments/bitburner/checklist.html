Early Game Focus

  1. Run begin.js to initialize the entire automation system
  2. Wait for connect.js to finish scanning and creating accessServers.txt
  3. Let allAutoHack.js start hacking all accessible servers
  4. hackNEt.js will automatically manage hacknet nodes for passive income
  5. autoNuke.js will automatically nuke new servers as you level up
  6. Buy needed augmentations from factions

Common Issues

  • Low RAM - Not enough memory to run all autoHack.js instances, reduce threads per server
  • High security - autoHack.js will weaken automatically, but may take time on high-security servers
  • Missing port tools - connect.js and autoNuke.js need port-opening tools (brutessh.exe, etc.)
  • accessServers.txt empty - Run connect.js manually if begin.js didn't create it properly
  • Scripts not found - begin.js creates all scripts automatically, but check if they exist
  • autoNuke.js not working - Make sure you have the required hacking level and port tools
