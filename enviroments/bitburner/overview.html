Returning to Bitburner

Bitburner is a programming-based hacking simulation where you automate your own growth. You move from simple scripts to a full network of servers, balancing money, security, and upgrades while your code runs 24/7.

Theme note: I use the Dark+ theme in Bitburner, and this site matches that same Dark+ look.

What The Game Is

At first, you manually run scripts to hack beginner servers. As your hacking level rises, you buy or crack into more systems and automate everything with better orchestration. The game becomes a loop of writing better code, upgrading infrastructure, and scaling income.

Main Gameplay Loop

  1. Scan and gain access to as many servers as possible.
  2. Lower security and grow server money pools.
  3. Run hack cycles for steady income.
  4. Reinvest into hacknet nodes and purchased servers.
  5. Expand automation with smarter scripts.

Why I Use Automation

  • It removes repetitive manual commands.
  • It keeps income stable while I focus on strategy.
  • It helps me scale faster across many servers.
  • It makes progression smoother after resets.

Bitburner Systems

System What it does Why it matters
Hacking Steals money from target servers. Main money source early and mid game.
Grow/Weaken Restores money and lowers security levels. Keeps targets profitable for long-term cycles.
Hacknet Generates passive money with node upgrades. Provides stable background income.
Server Ownership Lets you buy servers to run more threads. Increases automation scale and total profit.
