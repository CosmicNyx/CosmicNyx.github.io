Script Notes

This page documents the automation scripts I actively use in Bitburner and how they work together.

My Scripts

begin.js

Main orchestrator script that initializes the entire automation system. Runs connect.js to scan network, starts allAutoHack.js for hacking, hackNEt.js for passive income, and autoNuke.js for auto-nuking as you level up.

connect.js

Scans the entire network, gains root access to all possible servers using available port-opening tools, and backdoors servers automatically. Creates accessServers.txt and noAccessServers.txt files.

autoHack.js

Individual server hacking script that weakens, grows, and hacks a target server. Maintains optimal security and money levels, continuously loops to maximize profit from a single target.

allAutoHack.js

Reads accessServers.txt and runs autoHack.js on all accessible servers simultaneously. Distributes RAM evenly across all targets and skips servers already being hacked.

hackNEt.js

Automated hacknet node management. Spends 15% of available money evenly across all nodes, upgrading levels, RAM, and cores. Runs continuously in the background for passive income.

autoNuke.js

Background monitor that automatically nukes and backdoors servers as your hacking level increases. Checks every 30 seconds and runs begin.js when new servers are nuked to update access files.
